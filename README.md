A TypeScript utility library for a privacy-first, decentralised social protocol built on Base. This is the frontend service layer — it sits between the ZK smart contracts and the UI, handling everything from contract interactions and wallet configuration to identity verification, reputation scoring, and gasless transactions.
The library covers fourteen modules across five domains. On the blockchain side, it provides a central contract address registry with full ABI exports, a wagmi and RainbowKit configuration targeting Base mainnet with wallet priority ordered to minimise WalletConnect relay dependency, and an EIP-4337 paymaster integration that sponsors the first five tips per user through Base Account Abstraction.
For market data, a multi-source price fetcher chains CoinGecko, Jupiter, Binance, and Coinbase in sequence with per-request AbortController timeouts and static fallback prices for eighty-plus tokens.
The identity and reputation layer is where it gets interesting. Gitcoin Passport scores are fetched and cached for seven days, KYC status extracted from BrightID, Civic, Idena, Holonym, and Worldcoin stamps. A unified 0-100 user rating is computed from four on-chain sources — activity, contributions, verification, and engagement — with red-to-green colour interpolation and six named levels. A separate reputation system maps posts, tips, staking, and followers to a point total with level progression at 250-point intervals.
The scam reporting module is a self-contained trust scoring system that calculates green and red flags from wallet age, staking duration, KYC status, and report history — designed to operate locally and sync to the on-chain ScamReports contract when connected. Wallet analysis pulls all of this together with live Basescan API data for wallet age and Gitcoin scorer API for passport verification.
Rounding it out: IPFS feed caching via web3.storage with localStorage fallback and 5-minute TTL, a Prisma singleton with graceful shutdown, a live user tracker built for WebSocket replacement, and a Hardhat test runner that produces structured JSON reports with feature flag detection.
This is a snapshot. The full project includes the application layer, ZK smart contracts, circuit setup, and deployment infrastructure — all separate. There is a lot more where this came from.
